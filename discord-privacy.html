Kebijakan Privasi Bot Discord

Terakhir diperbarui: 25 November 2026

Bot Discord "Aksara Dirg. - Chief of Staff" adalah asisten AI pribadi milik adtgoz (rahmattrippp@gmail.com). Bot ini hanya dipasang di server Discord milik pemiliknya sendiri dan tidak ditawarkan untuk umum.

Data yang diproses

  • Isi pesan, lampiran, dan pesan suara yang dikirim kepada bot (DM atau channel tempat bot berada), beserta ID pengguna, ID channel, dan ID pesan Discord.
  • Data ini dipakai hanya untuk memahami permintaan dan menjawabnya.

Pemrosesan dan penyimpanan

  • Pesan diproses oleh perangkat lunak Hermes Agent yang berjalan di server pribadi pemilik, dan dikirim ke penyedia model AI (Anthropic) untuk menghasilkan jawaban.
  • Riwayat percakapan disimpan di server pribadi pemilik dengan akses terbatas.
  • Pesan suara ditranskripsi secara lokal di server pemilik.
  • Data tidak dijual, tidak dibagikan ke pihak ketiga lain, dan tidak dipakai untuk iklan.

Penghapusan data

Permintaan penghapusan data dapat dikirim ke rahmattrippp@gmail.com. Mengeluarkan bot dari server menghentikan semua pemrosesan baru.
