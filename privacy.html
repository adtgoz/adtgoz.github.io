Kebijakan Privasi

Terakhir diperbarui: 25 November 2026

Aplikasi OAuth "rclone backup adtgoz-vps" adalah aplikasi pribadi yang hanya dipakai oleh pemiliknya (adtgoz, rahmattrippp@gmail.com) pada server pribadinya sendiri.

Data yang diakses

Dengan izin pemilik, aplikasi mengakses data Google milik pemilik sendiri (Google Drive, Gmail, Google Calendar, Google Docs, Google Sheets, Google Contacts, dan pengelolaan project Google Cloud milik pemilik) semata-mata untuk menjalankan backup dan tugas otomasi yang diminta pemilik.

Penggunaan dan penyimpanan

Data tidak dijual, tidak dibagikan ke pihak ketiga, dan tidak dipakai untuk iklan. Token akses disimpan terenkripsi atau dengan izin file terbatas di server pribadi pemilik. Backup dienkripsi sebelum diunggah ke Google Drive pemilik.

Pencabutan akses

Pemilik dapat mencabut akses kapan saja melalui https://myaccount.google.com/permissions.
